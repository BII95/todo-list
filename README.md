-Description
This project is a React application created with Vite. It is to-do list application that demonstrates structure and development workflow using Vite.

-Installation 
1. Clone repo 
git clone https://github.com/BII95/todo-list

2. Navigate to project directory:

3. Install project dependencies:

npm install

4. Start Vite development server by running:
npm run dev

5. Open local URL displayed in terminal in web browser.
http://localhost:5173
